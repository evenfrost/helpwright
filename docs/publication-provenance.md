# Clean-history publication

This repository was published from a reviewed Helpwright source snapshot on November 10, 2026. Its Git history begins at root commit `f25a9024413dee608c4bda69200ffcfd1b844e59`. Earlier private Git objects, branches, tags, workflow logs, local results, and Pact checkpoints are not part of this repository.

The portable Skill and its license are copied byte for byte. Existing source, synthetic evaluation cases, deterministic tests, build tooling, and experiment conclusions are preserved. Both release packages continue to use only `skills/helpwright/` for Skill contents.

Historical experiment notes are sanitized publication copies, not verbatim originals. Private conversation/project URLs and identifiers are replaced with descriptive references, a test mailbox is replaced with an `example.invalid` address, and personal home paths are generalized. Raw signed-in UI/tool catalog captures are retained privately and omitted from this publication. The methodology, synthetic prompts and responses included in the notes, numerical findings, and limitations remain unchanged.

Source commit hashes and release IDs in historical notes refer to the original private repository. They are provenance identifiers, not revisions or release records available from this repository. Historical archive checksums describe the bytes originally tested; they must not be reused as checksums for newly built archives. Some full experiment outputs were local-only before this export and remain unavailable in a checkout. Sanitization does not establish independent reproduction or additional host compatibility.

The owner selected `evenfrost/helpwright` as the clean destination and authorized renaming the original repository to keep it private. The public v0.2.0 release was built from the clean root, verified as a draft, published, and downloaded again without credentials. Both ZIPs passed their own checksums and exact tagged-source checks. Subsequent documentation commits record observed availability without rewriting the initial root or importing private history. See [distribution evidence](distribution.md) for installation and directory-discovery limits.
